# 飞机大战（网页版）

一个纯前端实现的小游戏，打开浏览器即可游玩，无需安装依赖。

## 玩法

- 使用 `WASD` 或方向键移动飞机
- 按 `空格` 持续射击（可一直按住）
- 也支持鼠标/触控拖拽移动飞机
- 击毁敌机会获得分数
- 敌机撞到你或者飞过底部会扣生命
- 生命归零后游戏结束

## 增益道具

- `+`：回复 1 点生命（上限 5）
- `2x`：短时间双发射击

## 运行

直接双击 `index.html` 或在仓库目录启动一个静态服务器，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。
